Məzmun və linklərə görə məsuliyyət

Xidmət təminatçısı kimi öz məzmunumuza görə ümumi qanunlar üzrə məsuliyyət daşıyırıq. Ötürülən və ya saxlanılan üçüncü tərəf məlumatlarına nəzarət etmək və ya qanunsuz fəaliyyətə işarə edən halları araşdırmaq öhdəliyimiz yoxdur.

Təklifimiz xarici veb saytlara linklər ehtiva edə bilər. Onların məzmununa təsir imkanımız yoxdur və buna görə məsuliyyət daşımırıq. Linklənmiş səhifələrə görə həmişə müvafiq provayder cavabdehdir.
